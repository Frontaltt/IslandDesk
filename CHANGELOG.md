# Changelog

## 1.3.1 — 2026-11-02

- Moved quick actions to the left brand area; actions appear on hover.
- Added previous, play/pause and next controls on hover over the media widget.
- Added a compact 10-band Equalizer APO settings preview below the expanded media card.
- Kept the equalizer preview explicit: it visualizes saved EQ settings, not live spectrum data.

## 1.3.0

- Added Studio language selection, theme and glass-style customization.
- Added a compact gaming mode with notification-first behavior and a selectable metric.
- Added clock/date and reorderable system widgets.
- Improved the notification presentation and hardware sensor diagnostics.
