# Installation and setup

## 1. Build both apps

Install the .NET 8 SDK, open PowerShell in the repository root and run:

```powershell
dotnet restore
dotnet build .\IslandDesk.sln -c Release
powershell -ExecutionPolicy Bypass -File .\BuildAll.ps1
```

`dist` contains `IslandDesk.exe` and `IslandDesk.Studio.exe`. Keep them in the same folder. The build script copies the included icon assets.

## 2. Create and install MSIX

For Windows notification access, use MSIX rather than launching the loose EXE:

```powershell
powershell -ExecutionPolicy Bypass -File .\BuildPackage.ps1
```

The packaging script publishes both apps self-contained, stages the manifest and assets, creates `IslandDesk.msix`, signs it with a local development certificate and asks for UAC permission to import that public certificate into the Local Machine `Root` and `TrustedPeople` stores. The temporary PFX (private signing key) is deleted after signing; the `.cer` is public and used only to trust this local development package.

If Windows asks for confirmation, verify that the certificate subject is `CN=Frontalt` and that the file is the `IslandDesk-dev-signing.cer` generated by this repository. Never trust an unrelated certificate. Do not publish the PFX or private key.

The package is version `1.3.1.0`; it can update older `1.1.x` and `1.2.x` test packages. If an older installation prevents updating, uninstall it from **Settings → Apps → Installed apps → Island Desk** and run the package script again.

## 3. Allow notifications

1. Launch **Island Desk** from Start after MSIX installation.
2. Approve its Windows notification access request.
3. Open **Settings → System → Notifications** and make sure notifications are enabled for the source apps (Discord, Telegram, etc.).
4. In Studio, leave **Notifications** enabled and add any unwanted source apps to the exclusion list if needed.

Island Desk receives new notifications after its listener starts. It does not retrieve private chat history or old notifications from messenger accounts. The Windows notification listener may not expose every custom notification layout or inline action.

## 4. Configure gaming mode

Open Studio → **Gaming & alerts**:

- Enable Gaming mode manually, or enable automatic fullscreen detection.
- Add process names such as `lmu.exe` to the game process list if you want to switch modes for a specific title.
- Select one metric: CPU, GPU, CPU temperature, GPU temperature, or none (glow only).
- Disable **Hide island in fullscreen apps** if you want the game-mode indicator to remain visible.

Use *Borderless Windowed* for the best compatibility. `Topmost` cannot guarantee visibility over exclusive-fullscreen DirectX applications.

## 5. Temperature sensors

The overlay uses LibreHardwareMonitor. Sensor access varies by hardware, BIOS, driver and Windows permissions.

- If CPU or GPU temperature remains `—°C`, test the portable `dist\IslandDesk.exe` created by `BuildAll.ps1` using **Run as administrator**. Some sensor drivers expose temperature probes only to elevated processes. Notification capture is intended for the MSIX-installed app, so use the MSIX version for normal use after the sensor check.
- Hover the temperature chip in the island to see the selected sensor name or the diagnostic hint.
- If only one value is missing, that specific sensor may not be exposed by the device/driver. The program intentionally does not substitute an unrelated motherboard reading.
- Update GPU drivers and check that the GPU is detected by LibreHardwareMonitor.

## 6. FPS

Install RivaTuner Statistics Server (RTSS), keep it running and enable its shared-memory support. FPS will appear only for games that RTSS is tracking.

## 7. Equalizer APO

Island Desk Studio controls Equalizer APO's configuration; it is not an audio driver itself.

1. Install Equalizer APO from its official project page: https://sourceforge.net/projects/equalizerapo/.
2. During setup, open Configurator and select the Windows playback device you actually use (headphones, speakers, DAC, etc.).
3. Restart Windows if the installer requests it.
4. Open Studio → **Hotkeys & audio** (Equalizer section), enable the EQ, and select the main `config.txt`. The default path is normally:

   `C:\Program Files\EqualizerAPO\config\config.txt`

5. Adjust the ten bands and save. Island Desk creates a backup named `config.txt.islanddesk.bak`, then includes `IslandDesk-Equalizer.txt` from the same folder.
6. To disable the EQ, switch it off in Studio and save. Island Desk removes its `Include` line and generated EQ file; the backup remains.

If Studio reports access denied, close it and reopen Studio as administrator once, then save again. Check that Configurator selected the active playback device. Apps using ASIO or WASAPI Exclusive may bypass system APO effects.

## 8. Settings location

`%AppData%\IslandDesk\settings.json`

The application stores settings locally. The project does not include telemetry or cloud sync.

## Hover controls and EQ preview

Hover over the custom Island Desk brand on the left to reveal the quick-action strip. Hover over the music widget to reveal previous, play/pause and next controls. The 10-band strip below the media card previews saved Equalizer APO band values; it is a settings preview, not a live audio spectrum analyzer. Click it to open Studio.
